# 安装与使用

**简体中文** | [English](en/INSTALLATION.md)

## 适用环境

本项目是基于 foobar2000 对应汉化版及兼容 TT / Georgia-ReBORN 环境的脚本修改集合，无法独立启动。不要将它当作完整主题直接安装到空白 foobar2000 环境中。

运行环境需保留原有未修改脚本、脚本组件、字体及其他资源。具体组件版本尚未提供，使用与稳定基线 FIX51 配套的汉化基台。

## 替换方法

1. 关闭 foobar2000。
2. 备份当前基台中的 `Base`、`Biography`、`Library` 对应脚本和个人配置。
3. 找到基台的脚本根目录：一般在 foobar2000 配置目录的 `georgia-reborn/scripts/` 下。以实际包含 `Base/gr-main.js` 等文件的位置为准，便携与标准安装的上层目录可能不同。
4. 将本仓库 `scripts/` 下的文件按同名相对路径覆盖到该目录。**合并覆盖文件，不先删除目标目录**，避免移除本仓库未收录的上游脚本。
5. 重启 foobar2000，检查歌词、详情页、简介及曲库能否正常显示。

| 仓库文件 | 基台目标位置（相对于实际脚本根目录） |
| --- | --- |
| `scripts/Base/*.js` | `Base/` 下同名文件 |
| `scripts/Biography/scripts/*.js` | `Biography/scripts/` 下同名文件 |
| `scripts/Library/` 内文件 | `Library/` 下相同相对路径 |

从 FIX51 升级到 FIX52，替换以下五个文件：

- `Base/gr-main-components.js`
- `Base/gr-details.js`
- `Base/gr-menu.js`
- `Base/gr-callbacks.js`
- `Base/gr-config-defaults.js`

已经安装 FIX50 时，升级到 FIX51 只需替换 `Base/gr-lyrics.js`。已使用 FIX52 的环境无需重复替换。

## 主要设置

- 唱机：现有唱片相关菜单中提供「唱机模式（原型测试）」选项。
- 中文竖排：详情页右键有「中文竖排」入口；默认布局下启用，适用于中文主原文，其他语言不强制转成中文竖排。
- 曲库流转：曲库提供「3D CD 流转设置」，可调整中央专辑大小等设置。
- 自定义主题歌词颜色：主界面歌词和简介歌词各自读取对应设置。修改简介歌词颜色时，应修改简介中的歌词常规色、高亮色等项。
- 星星动画：仅原文启用，译文不启用。

菜单完整路径会受现有汉化基台和页面状态影响，以实际菜单为准。

详情页字号可在「字体大小 → 详情」中调整至 48 像素，或在对应文字区域使用 Ctrl+滚轮。设置值与实际显示大小可能因详情区域的空间适配而不同。

波形条会优先使用缓存；没有缓存的曲目仍需要音频向导完成解析，耗时取决于文件、解析分辨率和运行环境。

## 使用检查与恢复

更新后先检查原文和译文、圆弧歌词、中文竖排、自定义颜色、唱机切换及曲库流转。反馈问题时说明页面模式、主题、窗口比例和操作步骤，截图中最好保留 CD 与歌词的相对位置。

如果替换后出现脚本错误，关闭 foobar2000，将备份文件按原路径恢复，再重新启动。保留错误提示中的文件名和行号，便于定位。不要靠清空个人配置来掩盖脚本版本混用问题。
