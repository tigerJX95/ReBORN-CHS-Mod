## 当前基线

- GitHub 只维护功能最全的最新版，不维护群内精简版，不生成安装包或 Releases 产物。
- 仓库保存 FIX51 的脚本和资源，不额外修改其运行逻辑。

## 已确定的设计约定

| 项目 | 约定 |
| --- | --- |
| 布局 | 专辑模式和唱机模式分别考虑比例；唱机优先保持方形，并保证详情信息空间 |
| 厂牌 Logo | 圆弧歌词仍可使用右下角 Logo 区域并渐隐，不强制为 Logo 预留空洞 |
| 中文竖排 | 共用设置入口；竖排遮罩作用于左右两侧 |
| 双语歌词 | 同句原文、折行及译文作为组合；星星动画只用于原文 |
| 自定义颜色 | 主界面与简介使用各自配置，不强制统一颜色来源 |
| 间奏提示 | 下方有空白优先下移；覆盖歌词时降低提示不透明度，不挤压歌词 |
| CD 圆弧 | 水平样式逐行定位；倾斜样式同句平行，整体避让 CD |
| 专辑流转 | 中央尺寸独立；连续滚动不加入流光，流光方案已经弃用 |
| 性能 | 保留缓存和区域绘制；新增效果尽量复用已有动画计时机制 |
