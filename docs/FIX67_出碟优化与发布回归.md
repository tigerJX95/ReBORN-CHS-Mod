## 功能范围

1. 渐进出碟 600 ms，快速出碟维持此前设置。
2. 正位 0° 滑出，滑出结束后再旋转。
3. 出碟滑动时避免 GDI+ 旋转帧预计算争用。
4. 动画中断时解除角度锁定，防止旋转恢复异常。
5. FIX67 已验收的 CD 原图中心、小白点、银色托圈、菜单及流转模式保持不变。

## 发布前专项检查（播放器实机）

1. 首次播放以及连续切歌：CD 从原图 0° 正位滑出，滑出完成后开始旋转。
2. 滑出中切换到 Library 再返回：角度锁定正确解除，无卡住或残影。
3. 滑出中暂停、停止、恢复：收碟与旋转状态正常。
4. 滑出中禁用再启用动画：下一次出碟从正位开始且可以正常旋转。
5. D2D 与 GDI+ 分别复验；高分辨率盘面测试快速切歌和流畅度。
6. 核对 CD 原图中心及白点、银色托圈、自定义菜单和 3D 流转功能。
