# FIX63 正式版验收记录

发布日期：2026-10-18

封板基线：FIX63 RC1（与已验收 pre8 的 31 个 JavaScript 运行文件完全一致）。正式版不修改运行脚本。

## 验收范围

- SACD ISO 连续切歌与波形条启停。
- 多封面轮播、CD 图片预计算、唱机播放与暂停恢复、最小化恢复。
- 歌词搜索、翻译动画、连续切歌时过期回调。
- 详情页、曲库、简介、右键菜单的中文正常显示；UTF-8 BOM 状态保留。
- 既有沉浸模式、滚动歌词和 CD 动画的回归。

验收结论：用户在 Windows 上确认 FIX63 RC1 最终回归通过。此结论不等于任何硬件或配置环境均无缺陷。

范围说明：SACD 多元数据字体额外实验、原生橙色波形风格及“关于/法律信息”菜单均未纳入正式版。
