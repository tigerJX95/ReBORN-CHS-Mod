# FIX67 正式版发布与回归检查

发布日期：2026-10-31。源码基线：`ReBORN-CHS-Mod_FIX67_flow_async_cache_candidate.zip`。

## 已验收
- FIX67 Preview 2 下拉菜单修复、CD 原图中心及中心小白点。
- 唱机 CD 图片加载联动与异常恢复候选功能。
- 3D 流转导航、无操作归位、异步封面缓存优化；用户已确认最后一版测试通过。

## 发布包仍建议复核
1. 备份当前播放器脚本，完整替换 `scripts/`，重启 foobar2000。
2. CD 有图、无图两种曲目切换；观察原图中心、白点、托圈、停止、出碟和旋转。
3. 开关普通详情页“显示碟片”，验证唱机可独立读取 CD 图片。
4. 3D 流转模式滚轮、左右键、空筛选、快速切歌、15/30 秒自动归位。
5. 大曲库连续滚动、搜索筛选切换及返回，检查图片是否错位、闪烁或卡住。
6. 自定义主题输入框、菜单首项/关闭、RCA Logo、沉浸模式与窗口恢复。
