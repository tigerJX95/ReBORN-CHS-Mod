# TT 修改版脚本

**简体中文** | [English](README.en.md)
基于 TT / Georgia-ReBORN 的 foobar2000 汉化版脚本修改项目，用于保存自用增强功能、修复代码及后续开发记录。

当前基线：**FIX51**。只维护功能最全的最新版，不维护群内精简版。

## 项目用途

保留每次脚本修改，便于查看差异、回退和继续开发。仓库提供 JavaScript 源码及相关资源，需要配合已有的 foobar2000 对应的汉化版和兼容的 TT / Georgia-ReBORN 环境使用。

## 主要增强功能

- 唱机模式、CD 转动及沉浸显示，包含界面切换、最小化恢复等相关修复。
- 详情页滚动歌词与 CD 圆弧歌词，原文、折行和译文组合显示。
- 卡拉 OK 逐字扫亮、扫亮样式和原文星星动画；译文不启用星星动画。
- 中文传统竖排，歌词页、详情页和唱机歌词区共用设置，详情页右键提供入口。
- 渐隐遮罩设置，中文竖排使用左右方向遮罩。
- 自定义主题歌词颜色：主界面与简介分别使用自己的颜色设置。
- 间奏倒计时，优先利用下方空白，覆盖歌词时降低提示不透明度。
- 曲库 3D 专辑流转、中央专辑独立尺寸、透视与疏密设置、无操作自动归位；流光效果已弃用。

## 使用前提

已有能够正常运行的 TT / Georgia-ReBORN 环境及其脚本组件、字体和资源。仓库包含 **31 个 JS 文件**及原有曲库资源，不是完整基台，也没有收录所有未修改的上游脚本。

原主脚本头部标注为 `3.0-x64-DEV`；曲库包元数据标注为 Library Tree `2.4.0`。这些是源码中的版本标识，不等于已核对的完整运行环境版本。具体 foobar2000、脚本组件及基台版本仍待补充。

替换前先关闭 foobar2000，并备份对应脚本和个人配置。按相对路径逐文件覆盖，保留基台其他文件，详见 [安装与使用](docs/安装与使用.md)。

## 版本维护

当前稳定基线为 FIX51。后续只提交最新脚本与文档，旧版由 Git 历史保留，不把旧 ZIP 和重复源码放进仓库，不配置编译或发布产物流程。
